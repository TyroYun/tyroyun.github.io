# tyroyun.github.io

Vibe_Dev_T 개발자 웹사이트 (GitHub Pages — https://tyroyun.github.io).

- `app-ads.txt` — Google AdMob 앱 인증용. AdMob은 스토어 등록정보의 개발자 웹사이트(Google Play '웹사이트', App Store '마케팅 URL')를 보고, 이 사이트 맨 위의 `app-ads.txt`를 읽는다. 파일 이름과 위치를 바꾸지 않는다.
- `index.html` — 만든 앱과 문의처. 앱이 늘면 카드를 더한다. 일어샘N6의 Google Play 링크는 Play에 공개된 뒤 더한다.
- 지원·개인정보 페이지는 앱마다 따로 있는 저장소(`nihongon6-support`, `nihongon6-privacy` 등)가 그대로 맡는다.
